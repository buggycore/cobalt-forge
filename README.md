Cobalt Forge is a standalone, single-process GitHub-compatible git forge written in C++20 with a Linux epoll HTTP/1.1 keep-alive engine and Node 22 trial launcher, serving Git Smart HTTP (v2/v0), REST v3, GraphQL v4, and MCP Streamable HTTP from a shared in-memory store.

## Run it

```sh
make && MAKEFUN_SHOP_TOKEN=dev-token ./bin/forge --port 8080
```
